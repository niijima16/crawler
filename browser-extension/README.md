# Pickup Assistant Handoff（ブラウザ拡張）

Pickup Assistant の「ブラウザで購入」で、確認画面をあなたのブラウザに1クリックで開くための拡張です。
拡張がやるのは、**ツールが用意したセッション（PHPSESSID）を dollyteria.com にセットして、確認画面のタブを開く**ところまでです。
**「購入する」ボタンは押しません**。最後の購入は、あなたが自分でクリックします（reCAPTCHA はそのブラウザで正規に動きます）。

確認画面では、同意チェックと「購入する」ボタンの位置まで自動でスクロールし、枠で囲んで目立たせます。**同意チェックは入れません・購入ボタンは押しません。** あなたが同意にチェックを入れて「購入する」を押します。

21時の更新直後など、開いた確認画面が混雑（503）で開けないときは、**拡張がそのタブを自動で再読み込み**します（間隔 約0.1〜0.6秒・開始から約1分まで）。確認画面が出たら止めて目立たせます。1分で開けないときは「再試行」ボタンを出します。再読み込みはそのページの GET のみで、購入・同意の操作はしません。読み込み失敗の検知に `webNavigation` 権限を使います。

## 読み込み方（Chrome / Edge などの Chromium）

1. `chrome://extensions` を開く
2. 右上の「デベロッパーモード」をオンにする
3. 「パッケージ化されていない拡張機能を読み込む」→ この `browser-extension/` フォルダを選ぶ

読み込むと、Pickup Assistant の画面（`http://127.0.0.1:8080`）で「拡張が有効」と表示され、「確認画面を開く」が1クリックで使えます。

## 権限

- `cookies` と `https://www.dollyteria.com/*`: 確認画面のためにセッション Cookie をセットする
- content script は、Pickup Assistant の画面（`127.0.0.1:8080` / `localhost:8080`）と、dollyteria.com の確認画面（`/cart/confirm`、スクロールと強調のみ）

ストアには公開しません（アンパック配布のローカル専用）。
